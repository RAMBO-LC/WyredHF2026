name: ux-review
description: Reviews the user experience of the interface. Checks clarity, hierarchy, feedback, and ease of understanding for a multi-agent demo.
---

Review the UI for:
- Can a judge quickly understand which agent is working?
- Is the final answer easy to find?
- Is memory visible and understandable?
- Are there any confusing or cluttered areas?
- Suggest 3 concrete UX improvements maximum.
