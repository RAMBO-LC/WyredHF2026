---
name: ui-builder
description: Builds clean, modern UI for multi-agent systems using React, Tailwind, and shadcn/ui style components. Focus on clarity, agent status, chat activity, and memory panels.
---

When building UI:
- Use clean dark theme by default
- Show clear agent status (Researcher, Analyst, Writer, Critic)
- Display agent activity in a chat-like feed
- Include a Shared Memory panel
- Keep layout simple and readable for demos
- Prefer shadcn/ui + Tailwind patterns
- Make it easy to demo in a hackathon setting
