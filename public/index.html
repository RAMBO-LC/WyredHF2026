Shared, persistent memory for AI agents.

SharedBrain is a local-first knowledge base with a multi-agent answer pipeline. Agents read and write one SQLite database, every answer cites its sources, and questions the knowledge base can't support are declined instead of guessed.

How it works

Four agents, one memory, every step visible

Each question runs through a fixed pipeline. You can watch every stage stream in, with its real timing, in the Ask view.

01

Researcher

Retrieval

Ranks document sections and ingested chunks with BM25, and pulls in related distilled memories.

02

Analyst

Scope check

Measures how much of the question the retrieved passages actually cover, and stops if it's too little.

03

Writer

Answer

Writes a cited answer with your configured LLM, or an extractive answer when no model is set.

04

Critic

Grounding check

Scores how much of the answer is supported by the sources before it's shown.

Features

Built to run on your laptop

No vector database, no hosted service, no required API key.

Local-first storage

Everything lives in a single SQLite file. Back it up by copying it.

Cited answers

Answers link each claim to the document section it came from. Click a citation to open the source.

Declines out-of-scope questions

If the knowledge base doesn't cover a question, SharedBrain says so rather than inventing an answer.

Bring your own model

OpenAI, any OpenAI-compatible endpoint such as Ollama or LM Studio, Gemini, or no model at all.

Drop-folder ingestion

Drop Markdown, text, JSON, CSV, or code files into a folder, or upload them in the browser. They're chunked and indexed automatically.

Reviewable memory

Distilled facts carry verbatim evidence, a status, and an audit trail. Approve, archive, or bundle them into context packs.

Knowledge graph

Documents and their links render as an interactive graph you can filter, search, and explore.

OpenAI-compatible API

Point existing tools at /v1/chat/completions and they'll get grounded context injected automatically.

Obsidian import & export

Move documents in and out as a Markdown vault with wikilinks intact.

API

Use it from anything

The web UI is a thin client over a plain HTTP API.

  • /api/ask returns a grounded answer with citations.
  • /api/tasks streams the agent pipeline as Server-Sent Events.
  • /api/ingest adds a document and distills memories from it.
  • /v1/* exposes memories, evidence, review items and context packs.
Full API reference → 
curl -s http://localhost:3000/api/ingest \
  -H 'content-type: application/json' \
  -d '{"title": "Deploy policy",
       "content": "# Deploy policy\nWe never deploy on Fridays."}'

curl -s http://localhost:3000/api/ask \
  -H 'content-type: application/json' \
  -d '{"question": "Can we deploy on Friday?"}'
const res = await fetch('http://localhost:3000/api/ask', {
  method: 'POST',
  headers: { 'Content-Type': 'application/json' },
  body: JSON.stringify({ question: 'How are webhooks signed?' }),
});
const { answer, citations, isRefusal } = await res.json();
from openai import OpenAI

# Any OpenAI client works against the grounded proxy.
# sb_live_demo_key_2026 is the built-in local development key.
client = OpenAI(base_url="http://localhost:3000/v1", api_key="sb_live_demo_key_2026")
reply = client.chat.completions.create(
    model="sharedbrain-core",
    messages=[{"role": "user", "content": "What are the rate limits?"}],
)
print(reply.choices[0].message.content)
